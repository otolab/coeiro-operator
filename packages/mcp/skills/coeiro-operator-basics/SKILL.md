# COEIRO Operator の基本

この Skill では、オペレータの割り当てと、利用シーンを問わない発話の基本を説明します。

## 発話とオペレータ

`say` に発話テキストを渡すと音声キューに追加され、ツールは再生完了を待たずに応答します。発話はユーザーの作業と並行して流れる通知です。短い話し言葉で伝え、コード・URL・長い説明は読み上げず、テキストで伝えてください。キャラクターや話速など、引数の意味と制約は各ツールの説明を参照してください。

オペレータは MCP クライアントの会話単位ではなく、サーバーが認識する端末セッション単位で割り当てられます。同じキャラクターを別セッションで同時に使うことはできません。予約は既定で4時間未使用のまま経過すると解放され、`say` を使うと延長されます。

- `operator_assign`: オペレータを割り当てます。キャラクターに挨拶が設定されていれば、自動で音声キューに追加されます。
- `operator_status` / `operator_available` / `operator_styles`: 現在の割り当て、利用可能なキャラクター、キャラクターのスタイルを確認します。
- `operator_release`: オペレータを解放します。設定された別れの言葉は自動では発話されません。

オペレータを使った具体的な場面ごとの振る舞いは、適用される利用シーン別 Skill に従ってください。
